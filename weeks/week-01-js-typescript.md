# Week 1 — JavaScript + TypeScript

**Goal:** Read and modify AI-generated frontend code without treating it as magic.

## Learn
### JavaScript minimum
- variables, functions, objects, arrays
- destructuring and spread
- map/filter/reduce
- modules/import/export
- promises and async/await
- try/catch
- fetch and JSON

### TypeScript
- primitive/object types
- interfaces vs type aliases
- unions and optional properties
- function typing
- generics basics
- unknown and type narrowing
- API response typing

## Source
- React TypeScript docs: https://react.dev/learn/typescript
- JavaScript reference: https://developer.mozilla.org/en-US/docs/Web/JavaScript
- TypeScript Handbook: https://www.typescriptlang.org/docs/handbook/intro.html

## Practice
Create a tiny TypeScript API client for `GET /candidates/:id` with typed response data, error handling and a mock JSON response.

## KPI / exit test
You can explain every important line in a typed API function and can change its types without asking AI what the syntax means.

**Time:** 6–8 hours total. Do not turn this into a full JavaScript course.
