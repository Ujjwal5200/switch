# Week 2 — React Fundamentals

**Dates:** 8–14 Sep 2026  
**Priority:** Supporting skill / fast track

## Objective

- props
- state + `useState`
- events
- conditional rendering
- lists/keys
- forms/controlled inputs
- `useEffect` basics
- `useRef` basics
- custom hooks basics
- Context basics
