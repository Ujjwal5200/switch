# Week 14 — AWS Foundations for AI Products

**Goal:** Understand the AWS pieces behind your architecture, not memorize services.

## Learn
- IAM
- VPC basics
- public/private subnets
- security groups
- ECR
- S3
- RDS/PostgreSQL
- ALB
- CloudWatch
- ECS vs EKS decision basics

## Source
- AWS Skill Builder: https://builder.aws.com/learn
- AWS Architecture Center: https://aws.amazon.com/architecture/
- AWS workshops: https://workshops.aws/

## Build
Move one non-critical NextSwitch component to AWS. Start with S3 or a small backend deployment before the full cluster.

## KPI / exit test
Given an AI product requirement, you can draw the AWS architecture and explain IAM, network boundaries, storage, compute and observability choices.

**Time:** 8–10 hours.
