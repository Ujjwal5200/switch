# Switch — AI Product Engineering Roadmap

A focused Aug–Dec 2026 plan to become an AI Product Engineer who can take an AI feature from architecture to backend/API, AI pipeline, frontend, containerization and deployment.

## How to use this repo

This is **not a course-completion tracker**. Each week has:

1. What to learn
2. What to build
3. What source to use
4. A concrete KPI / exit criterion

Use AI heavily for frontend implementation. Keep architecture, security, performance, reliability and cost decisions human-owned.
